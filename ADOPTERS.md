# KEIT adopters

These are the organisations and teams that have told us they run KEIT. Knowing who uses it helps us decide what to build next, and helps the next person judge whether KEIT fits their setup.

The list is self-reported. We have not verified any entry.

| Organisation | Provider | Cluster size | Since |
|---|---|---|---|
| | | | |

Organisation can be a name or "Anonymous". Provider is where the cluster runs, for example AWS EKS, Scaleway Kapsule, or bare metal. Cluster size is the number of nodes, or a range such as 10–50. Since is the month and year you started using KEIT.

## Add yourself

Either:

- Open a pull request that adds a row to the table above, or
- Open an issue with the ["I'm running KEIT" adoption report template](https://github.com/aknostic/keit/issues/new/choose) and we will add the row for you.

You do not need to name your organisation or share anything beyond the four columns. If you would like to say more about what you found, the adoption report template has room for it, and we will only publish it with your agreement.

Adding yourself does not commit you to anything.
